# 内容创作、作品与个人 IP

先明确谁会看、看完得到什么，以及用户有什么真实经验或可演示成果。用户已有素材和项目时直接整理，不先要求建立一套账号矩阵。

## 一次交付

围绕一个问题选一种载体：短口播、实际操作演示、图文、英文介绍或可运行工具。形成开头、核心案例、证据画面和下一步；标题只承诺内容确实能提供的价值。

Agent 完成资料核对、稿件、画面清单、字幕草案、素材整理等已授权的数字工作；用户负责真实经历、现场拍摄和表达。已有声音与影像才能据其制作成片；不能把脚本、示意图或虚构案例称为拍摄完成。

没有实际使用结果时展示如何用，不能编造效果。涉及第三方视频、课程或音乐时核对实际授权，公开可观看不等于可以整段搬运。

## 流量与风口

把热门话题、平台变化与本人能持续提供的价值分开。判断选题时核实日期、原始内容与受众问题，不把转发量等同商业需求。

提前确定一个可观察问题，例如观众是否理解用法、是否出现具体使用反馈。发布后记录内容、人工用时、真实反馈与可用的统计；涨粉或销售不是默认保证。不要为了“反学生思维”放弃原有义务或用挑衅制造内容。

## 学习与模仿

分析优秀内容的结构、问题选择和演示方法，再以自己的材料重新制作。原样复制与冒充原创不因某种理论标签而获得许可。对尚未溯源的“模仿无负担”等切片，只解释核对范围，不归纳成作者完整立场。

若只积累素材没有成品，把本轮缩到一个能看、能用或能录的小样。若效果很好但制作代价太高，简化形式，不仅提高发布频率。

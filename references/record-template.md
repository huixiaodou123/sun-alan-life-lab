# 实验记录模板

用于用户愿意持续记录或明确要求保存时。沿用已有文件，不强制创建目录；敏感信息只保存与任务必要且用户同意保留的部分。没有本地文件工具时，可在聊天中输出同样记录。

```markdown
# 实验：〔一句话目标〕

记录日期：
本轮期限：
实际可用时间 / 预算：
已有条件与限制：
已知事实：
尚未验证的假设：

## 本轮行动

主实验：
今天的第一步：
可选支撑动作：
时间安排与缓冲：
交付物 / 观察证据：
继续、缩小或停止的条件：

## 实际结果

做了什么（未做也如实记录）：
人工时间 / 成本：
证据文件或反馈：
用户体感：
暂不能判断的部分：

## 下一轮

继续 / 修改 / 换方案及依据：
唯一下一步：
下次回顾：
```

范例里的空栏是填写模板，不能当成实际结果。更新时保留关键旧版本或修改记录，避免把原计划改写成事后成功叙事。

# 理念映射与组合方式

以下是本项目的操作化设计。来源与核对范围见 [sources.md](sources.md)，完整研究入口见 [topic-map.md](topic-map.md)。主题允许增加、合并、分歧和修正，不把当前分类称作嘉宾共同发布的体系。

| 讨论主题 | 保留的实践问题 | 本项目如何处理 |
|---|---|---|
| 孙学 | 有限资源投向哪里，怎样发现机会并修正认知？ | 先明确标准与机会成本，再探索候选，用小实验检验需求和选择。 |
| 薄肌 | 怎样主动管理身体，形成能持续的实践？ | 从已有运动、恢复和限制出发，记录活动与体感；不把某种体型等同健康或个人价值。 |
| 英语 / 雅思 | 语言怎样帮助真实交流，考试怎样检验部分能力？ | 场景输出与反馈优先；考试目标另外按官方四项要求管理。“雅思”是用户要求纳入的学习方向。 |
| 黄毛 | 怎样自主呈现、敢于表达，减少无关评价的阻碍？ | 允许审美选择与小范围表达，区分嘲讽和具体反馈，尊重双方边界。 |
| AI | 怎样减少准备成本，让行动有连续记录？ | 交给 Agent 资料、草稿、练习与复盘工作；用户保留目标、真实实践和价值取舍。 |
| 创作、流量、个人 IP | 怎样把经验变成别人能使用的内容？ | 围绕受众真实问题做小样，记录反馈，比较投入与用途；不保证涨粉或用争议代替价值。 |
| 注意力、自律、延迟享受 | 怎样减少生活中的冲突，让目标能做下去？ | 检查恢复、负担与环境，做一次有限调整；不要求戒掉全部娱乐，也不把休息视作失败。 |
| 自由、消费、体验 | 我到底在追求什么，什么负担可以减少？ | 比较本人真实收益与成本，保留义务与重要关系；不统一要求买房、负债、极简或放弃消费。 |
| 大水、过日子、情绪稳定等延伸 | 这些讨论对应了什么真实需要？ | 先核对是谁说了什么，再处理日常习惯、边界和可持续性；没有出处的梗不变成处方。 |

## 组合要围绕一个真实交付

例如用户想介绍自己的骑行工具给海外用户：主实验是完成一次简短英文演示。英语模块处理表达，决策模块帮助明确受众，表达模块帮助呈现。运动仍按原有安排，不额外塞进每日任务。

当用户只想准备雅思，直接进入考试目标；当用户只想了解大水或薄肌讨论，先解释来源与不同含义。用户的任务决定路线，主题标签不能代替需求。最新流行名称可能指同一个问题，优先合并重复，不给每个梗单独增加一份日常任务。

## 实用的取舍

- **开图**用于建立比较基础；达到本轮投入上限后转入试用或交付，避免无限收集。
- **自主**允许拒绝不适合自己的目标；不把“别人反对”自动解释为嫉妒。
- **小我**意味着证据能改变决策；不等于否定自我，也不以讨好所有人为目标。
- **创造**需要可使用的成果；学习和休息也有独立价值，无需把全部生活变成作品。
- **信任 AI**适合转化为愿意尝试与及时反馈；多数模型一致不构成事实证明。

这些取舍是本项目的执行规则。讨论嘉宾观点时不得倒过来声称他们已接受全部规则。
